# Code Review Guidelines

## Process

1. Skim the change for intent and scope.
2. Check correctness and edge cases.
3. Verify tests and error handling.
4. Flag security, privacy, and performance risks.
5. Suggest a clear next action (merge / revise / follow-up).

## Output template

- **Summary** — one paragraph
- **Blockers** — must-fix before merge
- **Suggestions** — optional improvements
- **Nits** — style / naming only
